## 1. コードの決まり

| 1文字目 | 種類 | 表示 |
| --- | --- | --- |
| E | エラー | 赤のアラート、または入力欄の下の赤字 |
| W | 警告 | 黄のアラート |
| I | 情報・完了 | 緑（完了）か青（説明）のアラート、または0件のときの灰色の文。入力欄に最初から入れておく文のひな形（例：SM-07 の通知文の初期値 I2702）にも使う |
| C | 確認 | `data-confirm` の確認ダイアログ |
| N | お知らせの件名（N00xx）・本文（N10xx） | お知らせ一覧 |

2〜3桁目は画面の番号です：01＝SC-01、02＝SC-02、03＝SC-03、11〜16＝SB-01〜06、21〜31＝SM-01〜11（SM-06-1 は 26）、41〜44＝SA-01〜04。

- 文はすべて `src/main/resources/messages.properties`（UTF-8）に書きます。2章の表と3章のファイルは同じ内容です。
- `{0}` などは引数です。Java では `new BusinessException("E2605", name, date)`、テンプレートでは `#{E2605(${name}, ${date})}` で渡します。
- 文の中にシングルクォート（'）を使ってはいけません（MessageFormat で特別な意味があるため）。
- 新しいメッセージを足すときは、先にこの一覧を改版します。
