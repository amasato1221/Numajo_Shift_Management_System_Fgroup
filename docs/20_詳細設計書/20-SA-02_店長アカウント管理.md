## 2. 処理

### 2.1 初期表示（GET /admin/managers）

1. `ManagerAccountService#findAll()` → `List<ManagerRow>`（ロック中＝`locked_until > now`）。
2. model：`managers`、`managerForm`（空）。`admin/managers` を返す。

### 2.2 作成（POST /admin/managers）

1. 入力チェック。エラー → 2.1 の `managers` を入れ直して再表示。
2. `ManagerAccountService#create(form, adminUserId)`（`@Transactional`）：
   1. ログインIDの重複（全ユーザー）→【エラー】E4207（`bindingResult.rejectValue("loginId", "E4207")` にして再表示）
   2. 初期パスワード：`PasswordGenerator#generate()`。
   3. `users` に1行：role＝MANAGER、`must_change_password`＝TRUE、`is_active`＝TRUE、`is_trainee`＝FALSE。
   4. 操作ログ `MANAGER_CREATE`（target：`user:{id}`、detail：`loginId={ログインID}, name={氏名}`）。
3. `redirect:/admin/managers`、フラッシュ `initialPassword`、`initialPasswordName`、`successMessage`＝I4202。

### 2.3 停止（POST /admin/managers/{id}/stop）

1. `ManagerAccountService#stop(id, adminUserId)`：
   1. 対象がない・MANAGER でない → 404。
   2. すでに停止中 →【エラー】E4208
   3. `is_active`＝FALSE。操作ログ `MANAGER_STOP`。
   4. 停止した人がログイン中なら、その人の次のリクエストでログアウトさせる。これは `UserActiveCheckFilter`（ログイン中のリクエストのたびに `users.is_active` を確かめ、FALSE ならセッションを無効にして `/login?disabled` へリダイレクト）が行う（94_セキュリティ設計書。SM-03 でバイトを無効にしたときも同じ）。
2. `redirect:/admin/managers`、フラッシュ I4204（引数：氏名）。

### 2.4 再開（POST /admin/managers/{id}/resume）

1. `ManagerAccountService#resume(id, adminUserId)`：ない → 404。有効 →【エラー】E4209。`is_active`＝TRUE、操作ログ `MANAGER_RESUME`。
2. `redirect:/admin/managers`、フラッシュ I4205。

### 2.5 パスワード初期化（POST /admin/managers/{id}/reset-password）

1. `ManagerAccountService#resetPassword(id, adminUserId)`：ない・MANAGER でない → 404。新しい初期パスワード、`must_change_password`＝TRUE、`failed_login_count`＝0、`locked_until`＝NULL。操作ログ `MANAGER_PASSWORD_RESET`。
2. `redirect:/admin/managers`、フラッシュ `initialPassword`、`initialPasswordName`、`successMessage`＝I4206。

**最後の店長を停止してもよい：** 管理者がいつでも再開できるため、止めません。停止すると有効な店長が0人になるときは、確認文 C4201 のかわりに C4203「有効な店長がいなくなります。…」を出します（`row.lastActive` が true の行）。

## 4. メッセージ

## 5. 操作ログ

MANAGER_CREATE、MANAGER_STOP、MANAGER_RESUME、MANAGER_PASSWORD_RESET

## 6. テストの観点

| No. | 観点 | 期待結果 |
| --- | --- | --- |
| 1 | 作成 | role＝MANAGER、初期パスワードが1回だけ出る、操作ログ |
| 2 | バイトのログインIDと同じ | E4207 |
| 3 | ふりがな空で作成 | 作成できる |
| 4 | 停止 | その人はログインできない。ログイン中なら次の操作でログイン画面へ |
| 5 | 停止中を停止（二重送信）・有効を再開 | E4208・E4209 |
| 6 | バイトのIDで停止 | 404 |
| 7 | ロック中の店長を初期化 | ロック解除 |
| 8 | 有効な店長が1人だけ | 停止の確認が C4203 |
