## 2. 処理

### 2.1 初期表示（GET /manager/skills）

1. `SkillService#findRows()`：職能を名前順に取り、`user_skills` の人数（有効なバイトだけ数える）を付ける。
2. `SkillService#getSlotSkillForm()`：`slot_required_skills` から `SlotSkillForm` を作る。
3. model：`skills`、`skillForm`（空）、`slotSkillForm`。`manager/skills` を返す。

### 2.2 追加（POST /manager/skills）

1. 入力チェック。エラー → 2.1 の値を入れ直し、`skillForm` はそのままで再表示。
2. `SkillService#create(name, description, operatorId)`：
   1. 同じ名前がある（`existsByName`）→【エラー】E2404
   2. 1行追加。操作ログ `SKILL_CREATE`（target：`skill:{id}`、detail：名前）。
3. `redirect:/manager/skills`、フラッシュ I2402。

### 2.3 変更（POST /manager/skills/{id}）

1. 入力チェック。エラー → フラッシュ errorMessage（最初のエラーのコード）で `redirect:/manager/skills`。
2. `SkillService#update(id, name, description, operatorId)`：
   1. ない → 404。
   2. 名前を変えて、ほかの職能と同じ →【エラー】E2404
   3. 上書き。操作ログ `SKILL_UPDATE`（target：`skill:{id}`、detail：`{古い名前} → {新しい名前}`）。
3. `redirect:/manager/skills`、フラッシュ I2403。

### 2.4 削除（POST /manager/skills/{id}/delete）

1. `SkillService#delete(id, operatorId)`：
   1. ない → 404。
   2. 削除（`user_skills`・`slot_required_skills` の行は外部キーの ON DELETE CASCADE で消える）。
   3. 操作ログ `SKILL_DELETE`（target：`skill:{id}`、detail：名前）。
2. `redirect:/manager/skills`、フラッシュ I2404。

### 2.5 枠の必要職能の保存（POST /manager/skills/slot-required）

1. `SkillService#saveSlotRequired(daySkillIds, eveningSkillIds, operatorId)`：
   1. null は空のリストにする。存在しない職能IDがある →【エラー】E2405
   2. 日勤（slot_id＝1）・夕勤（slot_id＝2）の `requiredSkills` をそれぞれ置き換える。
   3. 操作ログ `SLOT_SKILL_UPDATE`（detail：`DAY=[職能ID…], EVENING=[職能ID…]`）。
2. `redirect:/manager/skills`、フラッシュ I2405。

**注意：** 必要職能を変えても、すでに出ている希望や割当は変えません。職能が足りない割当は、SM-06 の警告（職能不足）で気づけます。

## 6. テストの観点

| No. | 観点 | 期待結果 |
| --- | --- | --- |
| 1 | 名前が空・51文字 | E2401・E2402 |
| 2 | 同じ名前で追加・変更 | E2404 |
| 3 | 自分と同じ名前のまま説明だけ変更 | OK |
| 4 | 持っている人がいる職能を削除 | 職能と user_skills の行が消える |
| 5 | 日勤に「レジ」を必須にする | レジのない人は SB-03 で日勤を選べない |
| 6 | 必須を全部外す | 全員どの枠も選べる |
| 7 | 存在しない職能IDを送る | E2405 |
