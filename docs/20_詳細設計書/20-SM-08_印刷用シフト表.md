## 1. 印刷の形

- 用紙：A4横。CSSに `@page { size: A4 landscape; margin: 10mm; }` を書く。
- 1期間（最大16日）を1枚に収める。文字の大きさは 9pt、表の行の高さは 6mm。21人をこえて2枚目に分かれるときは、見出し行を `thead { display: table-header-group; }` で各ページにくり返す。
- 色：印刷でも見えるよう、日勤・夕勤は色だけでなく記号（☀・☾）でも区別する。`-webkit-print-color-adjust: exact; print-color-adjust: exact;` を付ける。
- 画面で開いたときだけ、上に「印刷する」「閉じる」ボタンを出す（`@media print { .no-print { display: none; } }`）。

```
┌────────────────────────────────────────────────────┐
│ セブンイレブン 三島駅西通り店　シフト表　2026/11/1(日)〜11/15(日)     出力 2026/10/20 18:40 │
├────────┬──────┬──────┬────┬──────────────────┤
│ 氏名        │ 1(日)      │ 2(月)      │ …      │ 出勤日数                             │
├────────┼──────┼──────┼────┼──────────────────┤
│ 山田 太郎   │ ☀8-17     │ ☾17-22    │        │ 2                                    │
│ 佐藤 花子 研│ 13-22     │ 欠☀8-17   │        │ 1                                    │
├────────┼──────┼──────┼────┼──────────────────┤
│ ☀日勤 人数  │ 2/2        │ 1/2 ▲     │        │                                      │
│ ☾夕勤 人数  │ 2/2        │ 2/2        │        │                                      │
└────────┴──────┴──────┴────┴──────────────────┘
（未公開のときだけ、ななめに大きく「下書き（未公開）」の透かし）
```

## 2. 画面項目

| No. | 項目 | 表示元 | 内容 |
| --- | --- | --- | --- |
| 1 | 見出し | `storeName`、`period`、`printedAt` | 「{店舗名}　シフト表　yyyy/M/d(E)〜M/d(E)」、右に「出力 yyyy/MM/dd HH:mm」 |
| 2 | 表の列 | `table.days` | 1列目＝氏名、日付の列（上段 `d`、下段 `(E)`。土は青、日は赤）、最後＝出勤日数 |
| 3 | 表の行 | `table.rows` | SB-04 と同じ並び（有効なバイト全員＋割当がある無効なバイト、ふりがな順）。研修中は名前の後ろに「研」 |
| 4 | セル | `row.cells[date]`（`List<ShiftBadge>`） | 日勤「☀8-17」、夕勤「☾17-22」、時間指定「13-22」。1日に2つあれば縦に並べる。欠勤は「欠」を付けて取り消し線 |
| 5 | 出勤日数 | `row.workDays` | ASSIGNED の割当がある日の数（1日に2つあっても1日） |
| 6 | 人数の行 | `counts[date][slotId]` | 「割当数/必要数」。足りないときは「▲」を付けて太字（色に頼らない） |
| 7 | 透かし | `period.status` | PUBLISHED でないときだけ「下書き（未公開）」。`position: fixed`、灰色、45度 |
| 8 | 印刷する | ボタン（`.no-print`） | `data-print` 属性。app.js が `window.print()` を呼ぶ |
| 9 | 閉じる | ボタン（`.no-print`） | `data-close` 属性。app.js が `window.close()` を呼ぶ（SM-06 から別タブで開くため） |

## 3. 処理

### 3.1 表示（GET /manager/periods/{id}/print）

1. 期間がない → 404。
2. `ShiftTableService#build(period, true)`（欠勤も出す）で `ShiftTable` を作る。
3. 人数：`RequiredStaffService#requiredCounts(start_date, end_date)` と、`ShiftWarningService#countFor` と同じ数え方の `ShiftTableService#slotCounts(table)`（`Map<LocalDate, Map<Byte, Integer>>`）。
4. model：`period`、`table`、`required`、`counts`、`printedAt`（今）。`manager/print` を返す。
5. 状態が OPEN の期間でも開ける（割当は0件の表になる）。

## 7. テストの観点

| No. | 観点 | 期待結果 |
| --- | --- | --- |
| 1 | 公開済みの期間 | 透かしなし |
| 2 | 作成中の期間 | 「下書き（未公開）」の透かし |
| 3 | 欠勤のある日 | 「欠」と取り消し線、人数に数えない |
| 4 | 時間指定 13-22 | 日勤・夕勤の両方の人数に数える |
| 5 | 20人・16日を Chrome で印刷プレビュー | A4横1枚に収まる |
| 6 | 21人以上 | 2枚目にも見出し行が出る |
| 7 | 存在しない期間ID | 404 |
| 8 | バイトでURLを開く | SB-01 へリダイレクト |
