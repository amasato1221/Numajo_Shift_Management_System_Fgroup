## 2. 処理

### 2.1 初期表示（GET /staff/home）

1. `ym` を `YearMonth.parse` する。null・形式違いのときは今月（`YearMonth.now(clock)`）。
2. `StaffHomeService#getHome(userId, ym)` で `StaffHomeView` を作る。
   1. **次の出勤**：`ShiftAssignmentRepository#findNextShifts(userId, today, nowTime, PageRequest.of(0, 1))`
      - 条件：`user_id = :userId`、`status = 'ASSIGNED'`、期間の `status = 'PUBLISHED'`、（`work_date > :today`）または（`work_date = :today` かつ `end_time > :nowTime`）。
      - 並び：`work_date` 昇順、`start_time` 昇順。1件目を `NextShiftView` にする。
   2. **未提出の期間**：`ShiftPeriodRepository#findUnsubmitted(userId, now)`
      - 条件：`status = 'OPEN'`、`deadline_at >= :now`、その期間・ユーザーの `request_submissions` がない。
      - 並び：`deadline_at` 昇順。
   3. **新しいお知らせ**：`NotificationRepository#findTop3ByUserIdAndReadAtIsNullOrderByCreatedAtDescIdDesc(userId)`。
   4. **カレンダー**：`ShiftCalendarService#buildMonth(userId, ym)`（下の 2.2）。
3. `model.addAttribute("home", view)`、`staff/home` を返す。

### 2.2 カレンダーの作り方（ShiftCalendarService#buildMonth）

1. 表示の始まり＝その月の1日を含む週の月曜日、終わり＝末日を含む週の日曜日。
2. `buildBadges(userId, 始まり, 終わり)` で日付ごとのバッジを作る（2.3）。
3. 週ごとに7日の `CalendarDay(date, inMonth, today, badges, periodId)` を作る。
   - `inMonth`＝その月の日か。`inMonth` が false の日は `badges` を空にする。
   - `periodId`＝その日を含む期間のID（`start_date <= date <= end_date`）。なければ null。
4. `MonthCalendar(ym, weeks, prevYm, nextYm)` を返す。

### 2.3 バッジの決め方（ShiftCalendarService#buildBadges）

期間ごとに、公開済みかどうかで出すものを変えます。

| 期間の状態 | 出すもの | バッジの種類 |
| --- | --- | --- |
| PUBLISHED | 自分の割当（ASSIGNED と ABSENT） | 日勤・夕勤・時間指定、ABSENT は欠勤 |
| OPEN・CLOSED | 自分の希望のうち `availability` が OK と TIME | 未確定（グレー） |

- 1日に複数あるときは開始時刻の順。
- 時間指定のアイコンは `ShiftTimeUtil#overlappingSlotCodes(start, end, slots)` で、重なる枠（DAY→☀、EVENING→☾）を並べる。時間の表示は `DateTimeUtil#shortRange(start, end)`（例：13-22、13:30-22）。
