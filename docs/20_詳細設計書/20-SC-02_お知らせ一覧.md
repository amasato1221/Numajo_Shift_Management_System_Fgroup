## 2. 処理

### 2.1 初期表示（GET /notices）

1. `NotificationService#findLatest(userId, 100)`：`notifications` を `user_id` で絞り、`created_at` の降順、`id` の降順で100件。
2. `NoticeRow`（id、type、typeLabel、title、body（100文字で切る）、createdAt、unread＝`read_at IS NULL`）に変換して `notices` に入れる。
3. `common/notices` を返す。

### 2.2 お知らせを開く（POST /notices/{id}/open）

1. `NotificationService#open(userId, notificationId)` を呼ぶ。
   1. `id` と `user_id` で1件取得。なければ `ResourceNotFoundException`（404）。
   2. `read_at` が null なら今の日時を入れる。
   3. `link_url` を返す。null か、`/` で始まらない、または `//` で始まる場合は `/notices` を返す（ほかのサイトへ飛ばさないため）。
2. `redirect:` ＋ 戻ってきたURL。

### 2.3 すべて既読（POST /notices/read-all）

1. `NotificationService#readAll(userId)`：`UPDATE notifications SET read_at = :now WHERE user_id = :userId AND read_at IS NULL`。
2. `redirect:/notices`、フラッシュ I0202。

## 3. お知らせの移動先（link_url）

お知らせを作るときに `NotificationService` が入れます（95_通知・定期処理設計書）。

| type | 宛先 | link_url |
| --- | --- | --- |
| DEADLINE | バイト | `/staff/requests?periodId={期間ID}` |
| PUBLISHED | バイト | `/staff/shifts?periodId={期間ID}` |
| CHANGED | バイト | `/staff/shifts?periodId={期間ID}` |
| VACANCY | バイト | `/staff/home` |
| CHAT | バイト | `/staff/chat` |
| CHAT | 店長 | `/manager/chats/{バイトのユーザーID}` |
