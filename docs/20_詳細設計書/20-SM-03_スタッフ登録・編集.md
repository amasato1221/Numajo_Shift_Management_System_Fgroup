## 2. 処理

### 2.1 登録画面（GET /manager/staff/new）

1. `StaffForm` を作る（`active = true`、`trainee = false`、`skillIds` は空）。
2. model：`staffForm`、`skills`（`SkillService#findAll()`、名前順）、`isNew = true`。`manager/staff-form` を返す。

### 2.2 登録（POST /manager/staff）

1. 入力チェック。エラー → 2.1 と同じ値を入れて再表示。
2. `StaffService#create(form, managerUserId)`（`@Transactional`）
   1. `UserRepository#existsByLoginId(loginId)` が true →【エラー】E2208
   2. `skillIds` のうち存在しないものがある →【エラー】E2209
   3. 初期パスワード：`PasswordGenerator#generate()`。
   4. `users` に1行：role＝STAFF、`password_hash`＝BCrypt、`must_change_password`＝TRUE、`is_active`＝TRUE、`failed_login_count`＝0。
   5. `user_skills`：選ばれた職能。
   6. `NotificationSettingService#createDefault(userId)`：`days_before` 1 と 3 の2行。
   7. `CalendarFeedService#getOrCreate(userId)`：購読トークンを作る。
   8. 操作ログ `STAFF_CREATE`（target：`user:{id}`、detail：`loginId={ログインID}, name={氏名}`）。
   9. `StaffCreatedResult(userId, initialPassword)` を返す。
3. フラッシュ `initialPassword`、`successMessage`＝I2202。`redirect:/manager/staff/{id}`。
4. 業務エラー → `bindingResult.rejectValue("loginId", "E2208")` のように該当項目のエラーにして再表示（E2209 は `skillIds`）。

### 2.3 編集画面（GET /manager/staff/{id}）

1. `StaffService#getForEdit(id)`：ユーザーを取得。ない、または role が STAFF でない → `ResourceNotFoundException`（404）。
2. `StaffForm` に今の値を入れる。
3. model：`staffForm`、`skills`、`staff`（`StaffDetailView`）、`isNew = false`。

### 2.4 更新（POST /manager/staff/{id}）

1. 入力チェック。エラー → 2.3 と同じ値を入れて再表示。
2. `StaffService#update(id, form, managerUserId)`（`@Transactional`）
   1. 対象がない・STAFFでない → 404。
   2. ログインIDを変えた場合、ほかの人と重複 →【エラー】E2208
   3. 存在しない職能 →【エラー】E2209
   4. name、nameKana、loginId、trainee、active、skills を上書き。
   5. 操作ログ `STAFF_UPDATE`（detail：変わった項目名をカンマ区切り。例：`name,skills,active`。何も変わっていなければ記録しない）。
   6. 有効から無効に変えたときだけ、その人の**今日以降の出勤（ASSIGNED）の割当**の件数を数えて返す（`ShiftAssignmentRepository#countAssignedFrom(id, today)`。期間の状態は問わない）。それ以外は 0 を返す。割当は消さない（店長が SM-06 で外す）。
3. `redirect:/manager/staff/{id}`、フラッシュ I2204。2-6 の件数が1以上なら、`warningMessage`＝W2201（引数：氏名、件数）も入れる（保存はする）。

### 2.5 パスワード初期化（POST /manager/staff/{id}/reset-password）

1. `StaffService#resetPassword(id, managerUserId)`（`@Transactional`）
   1. 対象がない・STAFFでない → 404。
   2. 新しい初期パスワードを作り、`password_hash` を更新。`must_change_password`＝TRUE、`failed_login_count`＝0、`locked_until`＝NULL。
   3. 操作ログ `STAFF_PASSWORD_RESET`（target：`user:{id}`）。
   4. 新しいパスワードを返す。
2. フラッシュ `initialPassword`、`successMessage`＝I2205。`redirect:/manager/staff/{id}`。

### 2.6 初期パスワードの作り方（PasswordGenerator#generate）

- 使う文字：`ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz23456789`（見まちがえやすい I・O・l・0・1 を除く）。
- `SecureRandom` で10文字選ぶ。英字と数字が両方1文字以上含まれるまで作り直す。
