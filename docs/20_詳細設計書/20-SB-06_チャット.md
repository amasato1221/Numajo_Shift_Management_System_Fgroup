## 2. 処理

### 2.1 初期表示（GET /staff/chat）

1. `ChatService#getConversation(staffUserId, viewerUserId)`
   1. `ChatMessageRepository#findLatest200(staffUserId)` で新しい200件を取り、`Collections.reverse` で古い順に並べ替える（201件目より古いものは出さない）。
   2. 相手（`sender_user_id` が自分以外）からのメッセージで `read_at` が null のものに今の日時を入れる（`ChatMessageRepository#markRead(staffUserId, true, now)`。`byStaff = true` は「バイトが見たので、バイト以外が送ったものを既読にする」。SM-11 では `false`）。
   3. `ChatMessageView(id, senderName, body, createdAt, mine)` のリストを返す。
2. model：`messages`、`chatForm`。`staff/chat` を返す。

### 2.2 送信（POST /staff/chat）

1. 入力チェック：`body` は `@NotBlank(E1601)`、`@Size(max=500, E1602)`。エラー → 2.1 の値を入れ直して再表示。
2. `ChatService#send(staffUserId = 自分, senderUserId = 自分, body)`（`@Transactional`）
   1. `chat_messages` に1行入れる。
   2. 有効な店長全員（`role = 'MANAGER' AND is_active = TRUE`）に CHAT のお知らせを作る。
      - 件名：N0005（「{送信者名}さんから新しいメッセージ」）、本文：メッセージの先頭50文字、link_url：`/manager/chats/{staffUserId}`。
3. `redirect:/staff/chat#latest`。
