## 1. 概要

GoogleカレンダーやAppleのカレンダーが定期的に読みに来るURLです。そのバイトの確定シフトを iCalendar 形式（RFC 5545）のテキストで返します。

**注意（10_基本設計書 2.1）：** Googleカレンダーは、Googleのサーバーから読みに来るため、インターネットから届くURLでないと反映されません。
そのため Googleカレンダーには、購読ではなく、割当ごとの「Googleカレンダーに追加」のリンクを SB-05 に出します（7章）。

## 2. 処理

1. URLの `{token}` が `^[A-Za-z0-9_-]{43}$` に合わない → 404。
2. `CalendarFeedService#buildIcs(token)`
   1. `calendar_feeds` を `token` で探す。なければ `ResourceNotFoundException`（404）。
   2. ユーザーを取得。`is_active = FALSE` なら 404。
   3. 対象の割当を取る：そのユーザーの `shift_assignments` のうち、`status = 'ASSIGNED'`、期間の `status = 'PUBLISHED'`、`work_date >= 今日 − 31日`。日付・開始時刻の順。
   4. 下の形式でテキストを作る（改行は CRLF）。
3. レスポンス
   - `Content-Type: text/calendar; charset=UTF-8`
   - `Content-Disposition: inline; filename="shift.ics"`
   - `Cache-Control: no-cache`

## 3. 出力の形式

```
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Fgroup//Shift Management System//JA
CALSCALE:GREGORIAN
METHOD:PUBLISH
X-WR-CALNAME:シフト（{氏名}）
X-WR-TIMEZONE:Asia/Tokyo
BEGIN:VEVENT
UID:shift-{割当ID}@shift-management-system
DTSTAMP:{今のUTC日時 yyyyMMdd'T'HHmmss'Z'}
DTSTART:{開始のUTC日時 yyyyMMdd'T'HHmmss'Z'}
DTEND:{終了のUTC日時 yyyyMMdd'T'HHmmss'Z'}
SUMMARY:{件名}
LOCATION:{店舗名}
END:VEVENT
（割当の数だけ VEVENT をくり返す）
END:VCALENDAR
```

- 日時は日本時間の日付＋時刻を UTC に直して書く（例：2026-11-16 17:00 JST → `20261116T080000Z`）。
- 件名：日勤 → `日勤 8:00-17:00`、夕勤 → `夕勤 17:00-22:00`、時間指定 → `時間指定 13:00-22:00`。
- テキストの中の `\`、`;`、`,`、改行は、`\\`、`\;`、`\,`、`\n` にする（`IcsUtil#escape`）。
- 1行が75バイト（UTF-8）を超えたら、CRLF ＋ 半角スペース1つで折り返す（`IcsUtil#fold`）。日本語の1文字の途中で切らない。
- 欠勤（ABSENT）になった割当は出さない（カレンダーから消える）。

## 7. Googleカレンダーへの追加リンク

課題期間中はアプリがインターネットから届かず、Googleカレンダーの購読（「URLで追加」）が反映されません（10_基本設計書 2.1）。そこで、割当ごとに Googleカレンダーの予定の作成画面を開くリンクを作り、SB-05 のカード2に出します（20-SB-05 1.2 No.9・10）。

- バイトがボタンを押すと、ブラウザ（スマホでは Googleカレンダーのアプリかブラウザ）で Googleカレンダーが開き、件名・日時・場所が入った状態になります。「保存」を押すと、自分の Googleカレンダーに予定が入ります。
- アプリから Google には通信しません。Google との承認（ログイン連携）の設定も、トークンを保存する表もいりません。Google にログインしていないときは、Google のログイン画面が先に出ます。
- 1件ずつ追加します。あとで割当が変わっても、欠勤になっても、追加した予定は変わりません（お知らせを見て、Googleカレンダーで直してもらう）。

### 7.1 対象の割当（CalendarFeedService#googleLinks）

1. そのユーザーの `shift_assignments` のうち、`status = 'ASSIGNED'`、期間の `status = 'PUBLISHED'`、`work_date >= 今日` を取る（`ShiftAssignmentRepository#findPublishedForFeed(userId, 今日)`）。日付・開始時刻の順。
2. 店舗名を取る（`StoreSettingService#get()`）。
3. 割当ごとに `GoogleCalendarLinkRow`（表示用の record。項目は `Long assignmentId, LocalDate workDate, String workDateLabel, String summary, String url`。承認されたら 30-07 4章に足す）を作る。`workDateLabel` は `DateTimeUtil#monthDay`（例：`11月20日(金)`）、`summary` は3章の件名、`url` は 7.2 の URL。

### 7.2 URL の形（CalendarFeedService#googleUrl）

```
https://calendar.google.com/calendar/render?action=TEMPLATE&text={件名}&dates={開始}/{終了}&location={店舗名}
```

- `{件名}`：3章の件名と同じ（`日勤 8:00-17:00`、`夕勤 17:00-22:00`、`時間指定 13:00-22:00`）。
- `{開始}`・`{終了}`：3章の DTSTART・DTEND と同じ UTC の日時（`IcsUtil#utc`）。末尾に `Z` が付くので、Googleカレンダーが日本時間に直して表示する。
- `{店舗名}`：店舗設定の店舗名。
- `text`・`dates`・`location` の値は、それぞれ `URLEncoder.encode(値, StandardCharsets.UTF_8)` でエンコードしてからつなぐ（空白 → `+`、`/` → `%2F`、`&` → `%26`、日本語 → `%E6…`）。
- 例：2026-11-20 の日勤 8:00〜17:00、店舗名「沼津店」

```
https://calendar.google.com/calendar/render?action=TEMPLATE&text=%E6%97%A5%E5%8B%A4+8%3A00-17%3A00&dates=20261119T230000Z%2F20261120T080000Z&location=%E6%B2%BC%E6%B4%A5%E5%BA%97
```
