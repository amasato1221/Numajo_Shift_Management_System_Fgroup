- 表に出すスタッフ：有効なバイト全員（割当がなくても行を出す）＋、その期間に割当がある無効なバイト。

## 2. 処理

### 2.1 初期表示（GET /staff/all-shifts）

1. `StoreSettingService#get().isShowOthersShifts()` が false → `redirect:/staff/home`、フラッシュ W1401。
2. 選択肢：`ShiftPeriodRepository#findByStatusAndStartDateGreaterThanEqualOrderByStartDateDesc(PUBLISHED, 今日の3か月前の1日)`。
3. 表示する期間：`periodId` があり選択肢に含まれる → その期間。含まれない → 404。なし → 選択肢のうち今日を含む期間、なければ選択肢の先頭（一番新しい）。選択肢が0件 → I1401。
4. `ShiftTableService#build(period, false)`（第2引数＝欠勤も出すか）で `ShiftTable` を作る。
   - `ShiftAssignmentRepository#findByPeriodIdWithUser(periodId)`（ASSIGNED と ABSENT の両方が返る）。`includeAbsent` が false なら ABSENT を除く。
   - スタッフの並び：`name_kana` 昇順、同じなら `id` 昇順（`name_kana` が null の人は最後）。
5. model：`periodOptions`、`period`、`table`、`myUserId`。`staff/all-shifts` を返す。
