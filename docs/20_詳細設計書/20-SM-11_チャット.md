## 2. 処理

### 2.1 初期表示（GET /manager/chats/{staffId}）

1. `ChatService#getStaffForChat(staffId)`：ユーザーがない・role が STAFF でない → 404。
2. `ChatService#getConversation(staffId, viewerUserId)`：SB-06 の 2.1 と同じ。ただし既読にするのは次の行だけ。
   - 見る人がバイト：`sender_user_id <> staffId`（店長が送ったもの）
   - 見る人が店長：`sender_user_id = staffId`（バイトが送ったもの）
   ```java
   @Modifying
   @Query("""
       UPDATE ChatMessage m SET m.readAt = :now
       WHERE m.staffUser.id = :staffId AND m.readAt IS NULL
         AND ((:byStaff = true AND m.senderUser.id <> :staffId) OR (:byStaff = false AND m.senderUser.id = :staffId))
       """)
   int markRead(@Param("staffId") Long staffId, @Param("byStaff") boolean byStaff, @Param("now") LocalDateTime now);
   ```
3. model：`staff`、`messages`、`chatForm`。`manager/chat` を返す。

### 2.2 送信（POST /manager/chats/{staffId}）

1. 入力チェック：`ChatForm`（E1601・E1602）。エラー → 2.1 の値を入れ直して再表示。
2. `ChatService#send(staffId, senderUserId = 店長, body)`（`@Transactional`）
   1. 相手がない・STAFF でない → 404。相手が無効 →【エラー】E3101
   2. `chat_messages` に1行（`staff_user_id`＝staffId、`sender_user_id`＝店長）。
   3. バイトに CHAT のお知らせ：件名 N0005（引数：店長の氏名）、本文：先頭50文字、link_url `/staff/chat`。
   4. ほかの店長にはお知らせを送らない。
3. `redirect:/manager/chats/{staffId}#latest`。業務エラー → フラッシュ errorMessage で同じURLへ。

## 6. テストの観点

| No. | 観点 | 期待結果 |
| --- | --- | --- |
| 1 | 店長・管理者の userId を staffId に | 404 |
| 2 | 開いたとき | バイトの未読が既読、店長が送ったものの read_at は変わらない |
| 3 | 送信 | 1行増え、そのバイトにだけお知らせ |
| 4 | 店長Aが送ったものを店長Bが見る | 右側に「店長A」の名前付きで出る |
| 5 | 無効なバイト | 送信ボタンが押せない。改ざんで送ると E3101 |
| 6 | 空・501文字 | E1601・E1602 |
