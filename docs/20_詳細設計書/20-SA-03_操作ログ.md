## 2. 処理

### 2.1 初期表示・検索（GET /admin/logs）

1. `LogSearchForm` に GET パラメーターを入れる（`@ModelAttribute`）。型が合わない値（日付の形式違い、`action` が列挙にない）は null として扱う（`BindingResult` のエラーは無視する）。
2. 既定値：`from` が null → 今日−6日、`to` が null → 今日、`page` が null・負 → 0。
3. `from > to` →【エラー】E4301 を `errorMessage` に入れ、結果は0件で表示（検索しない）。
4. `to − from` が 366日より長い →【エラー】E4302（同じく検索しない）。
5. `OperationLogService#search(form, PageRequest.of(page, 50, Sort.by(DESC, "createdAt").and(Sort.by(DESC, "id"))))`：
   ```java
   @Query(value = """
       SELECT l FROM OperationLog l LEFT JOIN FETCH l.user
       WHERE l.createdAt >= :fromAt AND l.createdAt < :toAt
         AND (:userId IS NULL OR l.user.id = :userId)
         AND (:action IS NULL OR l.action = :action)
       """,
       countQuery = """
       SELECT COUNT(l) FROM OperationLog l
       WHERE l.createdAt >= :fromAt AND l.createdAt < :toAt
         AND (:userId IS NULL OR l.user.id = :userId)
         AND (:action IS NULL OR l.action = :action)
       """)
   Page<OperationLog> search(@Param("fromAt") LocalDateTime fromAt, @Param("toAt") LocalDateTime toAt,
                             @Param("userId") Long userId, @Param("action") String action, Pageable pageable);
   ```
   `fromAt` ＝ `from.atStartOfDay()`、`toAt` ＝ `to.plusDays(1).atStartOfDay()`、`action` は `OperationAction#name()`（列は VARCHAR のため文字列で比べる）。
6. `page` が最後のページより大きい → 最後のページを表示（`page = totalPages − 1` でもう一度検索）。
7. model：`logSearchForm`、`logs`、`userOptions`、`actionOptions`。`admin/logs` を返す。

### 2.2 記録の仕方（OperationLogService#record）

```java
@Transactional(propagation = Propagation.MANDATORY)
public void record(Long userId, OperationAction action, String target, String detail)
```

- 呼び出し元の業務処理と**同じトランザクション**で入れる（業務処理が失敗したらログも残らない）。ログイン関係（LOGIN_SUCCESS など）は `LoginSuccessHandler` などから `recordInNewTransaction` で入れる。
- `ip_address` は `HttpServletRequest#getRemoteAddr()`（`RequestContextHolder` から取る。定期処理など、リクエストがないときは NULL）。
- `detail` が500文字を超えたら、497文字＋「...」にする。パスワード・トークンは**絶対に** detail に入れない。

### 2.3 操作の日本語名（OperationAction の label）

| 値 | 日本語名 | 値 | 日本語名 |
| --- | --- | --- | --- |
| LOGIN_SUCCESS | ログイン | SKILL_DELETE | 職能の削除 |
| LOGIN_FAILURE | ログイン失敗 | SLOT_SKILL_UPDATE | 枠の必要職能の変更 |
| LOGIN_LOCKED | アカウントのロック | REQUIRED_UPDATE | 必要人数の変更 |
| LOGOUT | ログアウト | REQUEST_PROXY_UPDATE | 希望の代理修正 |
| PASSWORD_CHANGE | パスワード変更 | ASSIGNMENT_ADD | 割当の追加 |
| STAFF_CREATE | スタッフの登録 | ASSIGNMENT_REMOVE | 割当の削除 |
| STAFF_UPDATE | スタッフの変更 | SHIFT_PUBLISH | シフトの公開 |
| STAFF_PASSWORD_RESET | スタッフのパスワード初期化 | ABSENCE_REGISTER | 欠勤登録 |
| MANAGER_CREATE | 店長アカウントの作成 | STORE_SETTING_UPDATE | 店舗設定の変更 |
| MANAGER_STOP | 店長アカウントの停止 | BACKUP_CREATE | バックアップ作成 |
| MANAGER_RESUME | 店長アカウントの再開 | SKILL_CREATE | 職能の追加 |
| MANAGER_PASSWORD_RESET | 店長のパスワード初期化 | SKILL_UPDATE | 職能の変更 |

列挙型に `private final String label;` を持たせ、画面では `${row.actionLabel}` を出す。
