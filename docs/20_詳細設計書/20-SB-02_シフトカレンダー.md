## 2. 処理

### 2.1 初期表示（GET /staff/shifts）

1. `PeriodService#findOptionsForStaff()` で期間の選択肢を作る。
   - 条件：`start_date >= 今日の3か月前の1日` かつ `start_date <= 今日の2か月後の末日`。並びは `start_date` 昇順。
2. 表示する期間を決める。
   1. `periodId` があり、選択肢に含まれる → その期間。
   2. `periodId` があるが選択肢にない・存在しない → `ResourceNotFoundException`（404）。
   3. `periodId` がない → 今日を含む期間。なければ、今日より後で一番近い期間。それもなければ選択肢の最後。
   4. 選択肢が0件 → I1202「表示できる期間がありません。」を出し、カレンダーを出さない。
3. `ShiftCalendarService#buildPeriod(userId, period)`：`buildBadges(userId, start_date, end_date)` を使い、期間の始まりの週の月曜から終わりの週の日曜までの `CalendarDay` を作る（期間外の日は `inMonth = false`）。
4. `canEditRequest` ＝ `period.status == OPEN` かつ `now <= deadline_at`。
5. model：`periodOptions`、`period`、`calendar`、`canEditRequest`。`staff/shifts` を返す。

## 6. テストの観点

| No. | 観点 | 期待結果 |
| --- | --- | --- |
| 1 | periodId なし、今日を含む期間がある | その期間 |
| 2 | periodId なし、今日を含む期間がない | 次の期間 |
| 3 | 存在しない periodId | 404 |
| 4 | 4か月前の期間の periodId | 404（選択肢にない） |
| 5 | OPEN・期限内 | 「希望を出す・直す」が出る |
| 6 | OPEN・期限切れ（BT-02前） | 出ない |
| 7 | CLOSED・PUBLISHED | 出ない |
| 8 | PUBLISHED 以外 | I1201 |
