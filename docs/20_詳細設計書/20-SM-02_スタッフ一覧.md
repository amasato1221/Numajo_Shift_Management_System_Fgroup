## 2. 処理

### 2.1 初期表示・検索（GET /manager/staff）

1. `status` が null・不正 → ACTIVE。`keyword` は前後の空白を取り、空なら null。
2. `StaffService#search(keyword, status)`
   1. `UserRepository#searchStaff(pattern, active)`（`active`：ACTIVE→true、INACTIVE→false、ALL→null）：
      ```java
      @Query("""
          SELECT DISTINCT u FROM User u LEFT JOIN FETCH u.skills
          WHERE u.role = jp.numajo.fgroup.shift.constant.Role.STAFF
            AND (:active IS NULL OR u.active = :active)
            AND (:pattern IS NULL
                 OR u.name LIKE :pattern ESCAPE '!'
                 OR u.nameKana LIKE :pattern ESCAPE '!'
                 OR u.loginId LIKE :pattern ESCAPE '!')
          ORDER BY u.nameKana ASC NULLS LAST, u.id ASC
          """)
      List<User> searchStaff(@Param("pattern") String pattern, @Param("active") Boolean active);
      ```
      `pattern` は Service で `"%" + LikeUtil.escape(keyword) + "%"` にして渡す（keyword が null なら null）。`LikeUtil.escape` は `!` → `!!`、`%` → `!%`、`_` → `!_` に置き換える（MySQLでは `\` がエスケープ文字として特別扱いされるため、`!` を使う）。
   2. `StaffRowView` に変換（ロック中＝`locked_until > now`）。
3. model：`staffList`、`keyword`、`status`。`manager/staff-list` を返す。
