## 2. 処理

### 2.1 初期表示（GET /manager/required）

1. `ym` が null・形式違い → 今月。
2. `RequiredStaffService#getDefaultForm()`：`required_staff_defaults` を14行取り、`RequiredDefaultForm` にする（行がなければ 0）。
3. `RequiredStaffService#getMonth(ym)`：その月の日ごとに、日勤・夕勤の必要人数（`requiredCount`）と、上書きかどうかを入れる。
4. model：`requiredDefaultForm`、`requiredOverrideForm`（`workDate` は空、`slotId`＝1）、`days`、`ym`、`prevYm`、`nextYm`。

### 2.2 既定値の保存（POST /manager/required/defaults）

1. 入力チェック。エラー → 2.1 の値を入れ直して再表示。
2. `RequiredStaffService#saveDefaults(dayCounts, eveningCounts, operatorId)`：14行を UPSERT（`save`）。操作ログ `REQUIRED_UPDATE`（detail：`defaults`）。
3. `redirect:/manager/required`、フラッシュ I2501。

### 2.3 上書きの保存（POST /manager/required/overrides）

1. 入力チェック。エラー → フラッシュ errorMessage で `redirect:/manager/required?ym={ym}`。
2. `RequiredStaffService#saveOverride(workDate, slotId, count, operatorId)`：
   1. `slotId` が 1・2 以外 →【エラー】E2504
   2. `required_staff_overrides` を `(work_date, slot_id)` で UPSERT。
   3. 操作ログ `REQUIRED_UPDATE`（detail：`override 2026-11-03 DAY=3`）。
3. `redirect:/manager/required?ym={workDateの年月}`、フラッシュ I2502。

### 2.4 上書きを戻す（POST /manager/required/overrides/delete）

1. `RequiredStaffService#deleteOverride(workDate, slotId, operatorId)`：行があれば削除、操作ログ `REQUIRED_UPDATE`（detail：`override delete 2026-11-03 DAY`）。
2. `redirect:/manager/required?ym={ym}`、フラッシュ I2503。

### 2.5 必要人数の決め方（RequiredStaffService#requiredCount）

```
requiredCount(workDate, slotId)
  = required_staff_overrides(work_date, slot_id) があればその値
  : なければ required_staff_defaults(day_of_week = workDate の曜日, slot_id) の値
  : それもなければ 0
曜日：DayOfWeek#getValue() % 7（月=1 … 土=6、日=7→0）
```

シフト作成（SM-06）では、1つの期間ぶんをまとめて取るため `RequiredStaffService#requiredCounts(from, to)`（`Map<LocalDate, Map<Byte, Integer>>`）を使います（SQLの回数を減らすため）。

## 6. テストの観点

| No. | 観点 | 期待結果 |
| --- | --- | --- |
| 1 | 既定値 −1／0／20／21／空 | E2502／OK／OK／E2502／E2501 |

| 6 | slotId＝3 を送る | E2504 |
