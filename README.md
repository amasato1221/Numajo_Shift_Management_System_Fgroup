# シフト管理システム

企業課題F班（新井・栗原・川端）で作る、コンビニ店舗向けのシフト管理システムです。バイトのシフト希望の提出、店長のシフト作成・公開、欠勤時の欠員通知などを行います。

## 設計書

設計書は [docs/](docs/README.md) にあります。実装を始める前に、[docs/README.md](docs/README.md) の「読む順番」に沿って読んでください。

## 動かし方

PCの準備と起動の手順は [96_環境構築手順書](docs/96_環境構築手順書.md) にあります。開発には Eclipse を使います（VS Code の使用は禁止）。
